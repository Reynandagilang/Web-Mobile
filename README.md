# Web-Mobile (PlanOS — Planner & Reminder Suite)

Aplikasi web mobile-first modern untuk manajemen tugas harian, strategic planning roadmap, kalender jadwal, dan pomodoro focus timer dengan arsitektur 100% offline lokal di browser.

## 🚀 Fitur Utama
- **1. Tugas Harian**: Checklist prioritas P1/P2/P3, kategori label, alarm notifikasi browser, dan tugas berulang (recurring).
- **2. Strategic Planning**: Roadmap kuartal/tahunan dengan interactive subtask checklist & progress bar dinamis.
- **3. Mode Fokus (Pomodoro)**: Timer 25/5/15 menit untuk produktivitas kerja dengan pelacak sesi harian.
- **4. Kalender Agenda**: Timeline jadwal terintegrasi tugas & planning.
- **5. Habit Consistency Streak**: Pencatat rekor hari produktif beruntun.
- **6. Ekspor / Impor**: Dukungan ekspor laporan ke format Excel (CSV) dan backup data penuh (JSON).
- **7. Theme Engine**: Mode Gelap & Mode Terang.

## 🛠️ Menjalankan Proyek Lokal

```bash
# Install dependensi
npm install

# Jalankan server development
npm run dev

# Build untuk production
npm run build
```
